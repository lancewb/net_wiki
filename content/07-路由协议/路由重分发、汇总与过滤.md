# 路由重分发、汇总与过滤

## 路由重分发

重分发是把一个路由来源学习到的路由注入另一个路由协议。

例子：

```text
静态路由 -> OSPF
OSPF -> BGP
BGP -> OSPF
```

## 为什么危险

重分发可能导致：

- 路由环路。
- 路由黑洞。
- 大量无关路由扩散。
- 默认路由误传播。
- 主备路径失控。

## 路由汇总

汇总把多个更具体前缀合并成一个更大的前缀：

```text
10.10.0.0/24
10.10.1.0/24
10.10.2.0/24
-> 10.10.0.0/22
```

优点：

- 减少路由表规模。
- 隐藏内部拓扑。
- 提高稳定性。

风险：

- 汇总过粗可能吸引不存在网段流量，形成黑洞。

## 路由过滤

过滤用于控制哪些路由可以进入或离开某个协议/邻居。

常见工具：

- Prefix-list。
- Route-map/Policy。
- AS_PATH filter。
- Community filter。
- RPKI 状态过滤。

## 设计建议

- 在边界明确过滤。
- 默认拒绝，显式允许。
- 对默认路由传播格外谨慎。
- 重分发时设置 tag，防止回灌。
- 汇总时考虑 Null0/黑洞路由。
