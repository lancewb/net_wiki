# 网络拓扑类型总览

## 什么是网络拓扑

网络拓扑描述网络节点之间如何连接。它可以分为：

- 物理拓扑：真实线缆、机柜、光纤、无线覆盖如何连接。
- 逻辑拓扑：VLAN、子网、路由、隧道、策略上如何连接。
- 控制平面拓扑：路由协议邻居、BGP 对等体、SDN 控制器如何控制网络。
- 数据平面拓扑：流量实际经过哪些设备和链路。

同一个网络可能有完全不同的物理拓扑和逻辑拓扑。

## 常见拓扑

| 拓扑 | 特点 | 典型场景 |
|---|---|---|
| 星型 | 终端连接到中心设备 | 家庭、办公室接入层 |
| 树型 | 核心-汇聚-接入 | 园区网、传统企业网 |
| 环型 | 节点成环，有冗余 | 城域网、工业网 |
| 全网状 | 节点互联充分 | 小规模高可靠网络 |
| 部分网状 | 关键节点互联 | WAN、骨干网 |
| Spine-Leaf | 每个 Leaf 连所有 Spine | 数据中心 |
| Hub-Spoke | 分支连中心 | 企业 WAN、云组网 |
| Overlay | 虚拟网络叠在底层 IP 上 | 云、SD-WAN、VXLAN |

## 选型关注点

- 可扩展性：节点增加时是否容易扩容。
- 收敛速度：链路故障后多久恢复。
- 成本：端口、线路、设备、运维复杂度。
- 带宽：是否容易出现中心瓶颈。
- 安全：是否能按区域隔离和审计。
- 可观测性：是否容易定位真实路径。

## 拓扑图阅读方法

1. 找边界：内网、DMZ、公网、云、专线在哪里分界。
2. 找网关：每个子网的默认网关在哪里。
3. 找路由：默认路由、专线路由、VPN 路由怎么走。
4. 找安全设备：防火墙、WAF、NACL、安全组在哪里生效。
5. 找地址转换：NAT、SNAT、DNAT、负载均衡 VIP 在哪里发生。
6. 找回程：响应包是否能按可用路径返回。
