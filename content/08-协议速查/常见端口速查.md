# 常见端口速查

这张表只用于入门记忆。真实环境中端口可以自定义，不能仅凭端口判断应用。

| 协议/服务 | 端口 | 传输层 |
|---|---:|---|
| HTTP | 80 | TCP |
| HTTPS | 443 | TCP |
| HTTP/3/QUIC | 443 | UDP |
| DNS | 53 | UDP/TCP |
| DHCP Server | 67 | UDP |
| DHCP Client | 68 | UDP |
| SSH | 22 | TCP |
| RDP | 3389 | TCP/UDP |
| SMTP | 25 | TCP |
| SMTPS | 465 | TCP |
| Submission | 587 | TCP |
| IMAP | 143/993 | TCP |
| NTP | 123 | UDP |
| SNMP | 161/162 | UDP |
| IPsec IKE | 500 | UDP |
| IPsec NAT-T | 4500 | UDP |
| WireGuard | 常见 51820 | UDP |
| BGP | 179 | TCP |
| OSPF | IP 协议号 89 | IP |
