# IPv6 协议

## IPv6 为什么存在

IPv6 的主要目标是解决 IPv4 地址不足，并改进地址自动配置、扩展头、邻居发现等机制。

## 地址长度

IPv6 地址是 128 位，例如：

```text
2001:db8:1234:5678::1/64
```

`2001:db8::/32` 是文档示例前缀，不用于真实公网。

## 常见地址类型

| 类型 | 例子 | 用途 |
|---|---|---|
| Global Unicast | 2000::/3 | 全球可路由 |
| Link-local | fe80::/10 | 本链路通信、网关邻居 |
| ULA | fc00::/7 | 类似私有地址 |
| Multicast | ff00::/8 | 组播 |

## IPv6 与 NAT

IPv6 通常不需要 NAT 来节省地址。安全依赖防火墙策略，而不是“没有公网地址所以安全”。

## NDP 与 SLAAC

IPv6 使用 [[ARP 与 IPv6 NDP]] 做邻居发现。主机可以通过 SLAAC 根据路由器通告自动生成地址，也可以使用 DHCPv6。

## 双栈

现实网络常见双栈：

```text
同一终端同时有 IPv4 和 IPv6
```

应用访问域名时，如果同时有 A 和 AAAA 记录，客户端可能优先尝试 IPv6。

## 常见问题

- IPv6 能访问，IPv4 不能，或反过来。
- 防火墙只配置 IPv4，忽略 IPv6 入站。
- DNS 返回 AAAA 但路径不可达。
- PMTUD/ICMPv6 被阻断导致连接异常。
