# IPsec、WireGuard 与隧道

## 隧道是什么

隧道把一种网络包封装进另一种网络包里，让两个网络跨过中间网络互通。

```text
内层包：10.1.1.10 -> 10.2.2.20
外层包：公网 IP A -> 公网 IP B
```

中间互联网只看外层公网 IP，隧道端点解封装后再转发内层包。

## IPsec

IPsec 常用于站点到站点 VPN。它提供加密、认证、完整性保护。

常见组件：

- IKE：协商密钥和安全关联。
- ESP：加密和认证数据。
- Tunnel Mode：封装整个内层 IP 包。
- NAT-T：让 IPsec 穿过 NAT，常用 UDP 4500。

## WireGuard

WireGuard 是现代 VPN 协议，配置相对简单，基于 UDP 和公钥。常用于远程接入、站点互联、轻量隧道。

## GRE、VXLAN、Geneve

这些也属于隧道/封装技术，但不一定自带加密。生产中如果跨不可信网络，需要额外加密。

## 隧道常见问题

- MTU 变小导致大包异常。
- 感兴趣流/路由不一致。
- NAT-T 被防火墙拦截。
- 两端网段重叠。
- 加密算法或密钥不匹配。
