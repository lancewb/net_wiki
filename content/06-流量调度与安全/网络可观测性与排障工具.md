# 网络可观测性与排障工具

## 排障核心问题

网络排障通常围绕四个问题：

1. 包有没有发出去？
2. 包有没有到达中间设备？
3. 包有没有被改写、丢弃或转发到错误路径？
4. 回包有没有回来？

## 常用命令

| 工具 | 作用 |
|---|---|
| ping | 测连通性和 ICMP 回包 |
| traceroute/tracert | 观察三层路径 |
| mtr | 连续 traceroute 和丢包统计 |
| nslookup/dig | DNS 查询 |
| curl | HTTP/TLS 诊断 |
| tcpdump/Wireshark | 抓包 |
| ip route/route print | 查看路由表 |
| arp/ip neigh | 查看 ARP/NDP 邻居 |
| ss/netstat | 查看端口和连接 |

## 抓包位置

抓包要分段：

- 客户端本机。
- 默认网关。
- 防火墙内外接口。
- 负载均衡前后。
- 服务器网卡。
- 云流日志或镜像端口。

只在一个点抓包，容易误判。

## 典型定位流程

```text
DNS 是否正确 -> 路由是否正确 -> ARP/NDP 是否正确
-> 防火墙/NAT 是否放行 -> TCP/UDP 是否建立
-> TLS 是否成功 -> HTTP/应用是否正常
```
