# NAT、PAT 与 CGNAT

## NAT 是什么

NAT（Network Address Translation）会改写 IP 包中的源地址或目的地址。它常用于私有地址访问公网、公网入口映射到内网服务、地址重叠场景。

## 常见类型

| 类型 | 改写 | 场景 |
|---|---|---|
| SNAT | 改源地址 | 内网访问公网 |
| DNAT | 改目的地址 | 公网端口映射到内网服务 |
| PAT/NAPT | 改地址和端口 | 多台内网主机共用一个公网 IP |
| CGNAT | 运营商级 NAT | 多个用户共享运营商公网 IPv4 |
| Static NAT | 一对一映射 | 服务器固定映射 |

## PAT 示例

```text
内网连接：
192.168.1.10:51532 -> 93.184.216.34:443

NAT 后：
203.0.113.10:40001 -> 93.184.216.34:443
```

NAT 设备记录映射表：

| 内部五元组 | 外部五元组 |
|---|---|
| 192.168.1.10:51532 -> 93.184.216.34:443 TCP | 203.0.113.10:40001 -> 93.184.216.34:443 TCP |

响应包回来时，NAT 设备按表把目的地址改回内网地址。

## DNAT 示例

公网用户访问：

```text
198.51.100.20:443 -> DNAT -> 10.0.2.10:443
```

这常用于对外发布内部服务。实际生产中通常先到负载均衡或 WAF，再进入应用。

## CGNAT

CGNAT 是运营商把大量用户放在共享公网 IPv4 后面。用户路由器 WAN 口可能拿到 `100.64.0.0/10` 或其他运营商私网地址。

影响：

- 外部不能直接访问用户家庭服务。
- 端口转发可能无效。
- P2P、游戏、远程桌面、家庭 NAS 受影响。
- 日志审计需要记录公网 IP、端口、时间。

## NAT 的副作用

- 破坏端到端地址可见性。
- 需要连接状态，设备故障会影响会话。
- 端口资源可能耗尽。
- 某些协议把 IP 地址写进应用层，需要 ALG 或特殊处理。
- 排障时必须同时看 NAT 前和 NAT 后地址。

## IPv6 与 NAT

IPv6 地址空间大，通常不需要 NAT 来解决地址不足。但仍然需要防火墙控制入站访问。IPv6 中也可能存在 NPTv6 等前缀转换，但设计目标不同。
