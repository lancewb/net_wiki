# 零信任、SASE 与 ZTNA

## 核心思想

零信任不是某个单一产品，而是一种安全设计思想：不要因为流量来自内网就默认可信，访问应持续验证身份、设备状态、上下文和最小权限。

## 传统边界与零信任

传统模型：

```text
内网可信，外网不可信
```

零信任倾向：

```text
每次访问都验证，按身份和上下文授权
```

## ZTNA

ZTNA（Zero Trust Network Access）常用于替代一部分传统 VPN。用户不是先“进内网”，而是经过身份认证和策略判断后，只访问被授权的应用。

## SASE

SASE 把网络和安全能力云化组合，常包括：

- SD-WAN。
- 安全 Web 网关。
- CASB。
- ZTNA。
- 云防火墙。
- DLP。

## 网络拓扑变化

传统：

```text
分支/用户 -> 总部出口 -> 互联网/SaaS
```

SASE：

```text
分支/用户 -> 就近安全云节点 -> SaaS/互联网/私有应用
```

## 与本库其他主题的关系

零信任不会取消路由、DNS、NAT、防火墙、TLS，而是在这些基础之上加强身份和访问控制。
