# 代理、反向代理与 WAF

## 正向代理

正向代理代表客户端访问外部资源。企业常用它做：

- 员工上网审计。
- 访问控制。
- 恶意站点拦截。
- 缓存。
- 出口 IP 统一。

路径：

```text
客户端 -> 正向代理 -> 互联网网站
```

## 反向代理

反向代理代表服务器接收外部请求。客户端以为自己访问的是网站，实际先到反向代理，再由它转发到后端。

路径：

```text
用户 -> 反向代理 -> 后端服务
```

常见能力：

- TLS 终止。
- Host/Path 路由。
- 压缩和缓存。
- 限流。
- 灰度发布。
- 统一认证。

## WAF

WAF 是 Web 应用防火墙，工作在 HTTP/HTTPS 层，关注 Web 攻击：

- SQL 注入。
- XSS。
- 路径穿越。
- 恶意扫描。
- 异常请求体。
- Bot/爬虫控制。

## 与负载均衡关系

常见入口链路：

```text
DNS/CDN -> WAF -> L7 负载均衡/反向代理 -> 应用服务
```

有些产品把 WAF、CDN、LB、反向代理能力集成在一起。

## 风险

- 反向代理未正确传递真实客户端 IP。
- `X-Forwarded-For` 被伪造，后端误信任。
- WAF 规则误拦正常业务。
- TLS 在代理终止后，代理到后端未加密。
