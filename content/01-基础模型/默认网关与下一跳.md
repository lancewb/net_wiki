# 默认网关与下一跳

## 默认网关是什么

默认网关是主机不知道目的地怎么走时交给的三层设备。它通常是本地子网内的路由器接口、防火墙接口、三层交换机 SVI，或云平台虚拟网关。

例子：

```text
主机 IP：192.168.1.10/24
默认网关：192.168.1.1
```

访问 `192.168.1.20`：目的在本地子网，直接 ARP 对方。

访问 `8.8.8.8`：目的不在本地子网，发给默认网关。

## 下一跳是什么

下一跳是路由表选择出来的“下一个交付对象”。它可能是：

- 路由器邻居 IP
- 出接口
- 云路由目标，例如 Internet Gateway、NAT Gateway、Transit Gateway
- VPN 隧道
- 防火墙或负载均衡器

## 逐跳转发

IP 网络是逐跳转发，不是源主机一次性指定整条路径。

```mermaid
flowchart LR
  PC[PC] --> GW[默认网关]
  GW --> ISP1[运营商边界]
  ISP1 --> ISP2[骨干路由器]
  ISP2 --> DSTGW[对端边界]
  DSTGW --> Server[服务器]
```

每一跳都只关心：目的 IP 匹配哪条路由，下一跳是谁。

## 默认路由

默认路由用于匹配所有没有更具体路由的目的地：

```text
0.0.0.0/0 via 192.168.1.1
::/0 via fe80::1
```

在家庭网络里，路由器通常有一条默认路由指向运营商。在企业网络里，默认路由可能指向防火墙、上级路由器或 SD-WAN 设备。

## 常见问题

- 网关配错：只能访问本地网段，不能上网。
- 掩码配错：主机误以为远端地址在本地，反复 ARP 但没人回应。
- 双网卡双默认路由：回包路径异常，连接时通时不通。
- 云子网路由表错误：实例有公网 IP 但没有指向 Internet Gateway 的路由。
