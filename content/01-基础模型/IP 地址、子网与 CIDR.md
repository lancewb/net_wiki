# IP 地址、子网与 CIDR

## IP 地址的作用

IP 地址用于三层寻址。它回答两个问题：

- 这台设备是谁？
- 它属于哪个网络范围？

IPv4 例子：

```text
192.168.1.10/24
```

这里 `/24` 表示前 24 位是网络位，后 8 位是主机位。网络范围通常写成 `192.168.1.0/24`。

## 私有地址

常见 IPv4 私有地址段来自 RFC 1918：

| 地址段 | 常见用途 |
|---|---|
| 10.0.0.0/8 | 大型企业、云 VPC、大型内网 |
| 172.16.0.0/12 | 企业、容器、VPN |
| 192.168.0.0/16 | 家庭、小型办公室 |

这些地址不会在公网互联网中全局路由。要访问公网，通常需要 [[NAT、PAT 与 CGNAT]]。

## 公网地址

公网地址由运营商、云厂商或机构通过 RIR/ISP 分配，可在全球互联网中通过 BGP 宣告。公网地址稀缺，因此 IPv4 中 NAT 非常常见。

## CIDR 与最长前缀匹配

CIDR 用 `/前缀长度` 表示网络范围。路由转发时使用最长前缀匹配：

| 路由 | 范围 | 优先级 |
|---|---|---|
| 10.1.2.0/24 | 更具体 | 高 |
| 10.1.0.0/16 | 较宽 | 中 |
| 0.0.0.0/0 | 默认路由 | 低 |

如果目的 IP 是 `10.1.2.33`，同时匹配 `/24`、`/16`、`/0`，会选择 `/24`。

## 子网划分例子

把 `10.0.0.0/16` 划成多个部门：

| 子网 | 用途 |
|---|---|
| 10.0.1.0/24 | 办公网 |
| 10.0.2.0/24 | 服务器区 |
| 10.0.3.0/24 | 管理网 |
| 10.0.10.0/24 | 无线访客网 |

## 地址规划建议

- 不同站点、VPC、VPN 对端不要使用重叠网段。
- 预留增长空间，不要一开始把地址切得太碎。
- 管理网、业务网、办公网、访客网、容器网最好分开规划。
- 云上多区域、多账号、多集群时，应提前设计全局 IPAM。
