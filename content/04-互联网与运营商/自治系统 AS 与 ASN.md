# 自治系统 AS 与 ASN

## AS 是什么

自治系统 AS 是由一个或多个网络运营者管理、对外呈现统一路由策略的一组 IP 前缀和路由器。每个 AS 用 ASN 标识。

例子：

- 运营商可以有自己的 ASN。
- 云厂商可以有多个 ASN。
- 大型企业、大学、CDN 也可能有 ASN。

## ASN 的作用

ASN 用于 BGP 路由。BGP 更新中会携带 AS_PATH，表示到达某个前缀需要经过哪些 AS。

```text
203.0.113.0/24  AS_PATH: 64500 64496 64497
```

这表示到达 `203.0.113.0/24` 的路径会经过这些 AS。

## 公有 ASN 与私有 ASN

公有 ASN 可用于互联网全局路由。私有 ASN 用于内部或客户侧 BGP，不能泄露到公网路由表中。

常见私有 ASN 范围包括：

- 64512-65534
- 4200000000-4294967294

## AS 与 IP 前缀

一个 AS 可以宣告多个 IP 前缀。一个 IP 前缀通常应由有权使用该地址段的 AS 宣告。现实中还需要 RPKI、IRR、过滤策略等机制减少错误宣告和劫持。

## 为什么 AS 很重要

理解 AS 后才能理解：

- 互联网为什么能分布式运行。
- BGP 为什么是策略路由。
- 运营商互联、Peering、Transit 的商业关系。
- CDN/Anycast 如何把流量引到不同节点。
