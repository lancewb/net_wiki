# 术语总览

## 基础

| 术语 | 简明解释 |
|---|---|
| LAN | 局域网 |
| WAN | 广域网 |
| VLAN | 二层广播域隔离 |
| Subnet | 三层 IP 地址范围 |
| Gateway | 默认网关或网络出口 |
| Router | 三层转发设备 |
| Switch | 二层/三层交换设备 |
| Firewall | 安全策略和会话检查设备 |
| NAT | 地址转换 |
| VIP | 虚拟 IP，常用于负载均衡 |
| CIDR | 用前缀长度表示 IP 网段 |
| MTU | 链路可承载的最大三层包大小 |
| MSS | TCP 单段最大应用数据大小 |

## 互联网

| 术语 | 简明解释 |
|---|---|
| AS | 自治系统 |
| ASN | AS 编号 |
| BGP | AS 间路由协议 |
| IXP | 互联网交换中心 |
| Peering | 网络之间直接互联 |
| Transit | 向上游购买互联网可达性 |
| CDN | 内容分发网络 |
| Anycast | 多地宣告同一 IP，由路由引流 |

## 云

| 术语 | 简明解释 |
|---|---|
| VPC/VNet | 云上的逻辑私有网络 |
| Subnet | 云网络中的子网 |
| Route Table | 云路由表 |
| Internet Gateway | 云公网入口/出口目标 |
| NAT Gateway | 私有资源主动访问公网 |
| Security Group | 实例/网卡级状态防火墙 |
| NACL/NSG | 子网或网卡级过滤规则，名称按云厂商不同 |
| Peering | 两个云网络私网互通 |
| Transit Gateway/Hub | 多网络集中互联 |
| Private Endpoint | 通过私网访问云服务 |

## 路由

| 术语 | 简明解释 |
|---|---|
| RIB | 控制平面候选路由表 |
| FIB | 数据平面转发表 |
| Next Hop | 下一跳 |
| Default Route | 默认路由 |
| IGP | AS 内路由协议 |
| EGP | AS 间路由协议 |
| OSPF | 链路状态 IGP |
| IS-IS | 链路状态 IGP |
| ECMP | 等价多路径 |
| VRF | 路由表隔离 |
