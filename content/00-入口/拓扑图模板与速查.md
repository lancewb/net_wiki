# 拓扑图模板与速查

这篇用于快速识别常见网络拓扑。读拓扑图时先确认：节点是什么、线代表什么、边界在哪里、路由在哪里、NAT 和安全策略在哪里发生。

## 家庭/SOHO

```mermaid
flowchart LR
  Device[手机/电脑] --> Router[家用路由器<br/>Wi-Fi DHCP NAT]
  Router --> CPE[光猫/CPE]
  CPE --> ISP[运营商]
  ISP --> Internet[互联网]
```

关键词：DHCP、NAT、Wi-Fi、CGNAT、IPv6、防火墙。

## 企业园区

```mermaid
flowchart TB
  Internet[Internet] --> FW[边界防火墙]
  FW --> Core[核心层]
  Core --> Dist[汇聚层]
  Dist --> Access[接入层]
  Access --> Users[办公终端/AP/打印机]
  Core --> Server[服务器区]
```

关键词：VLAN、STP/LACP、三层网关、OSPF、ACL、出口 NAT。

## DMZ

```mermaid
flowchart LR
  Internet --> FW1[外部防火墙]
  FW1 --> DMZ[DMZ<br/>WAF/LB/Web]
  DMZ --> FW2[内部防火墙]
  FW2 --> App[内部应用/数据库]
```

关键词：公网发布、DNAT、WAF、反向代理、最小权限。

## Spine-Leaf

```mermaid
flowchart TB
  S1[Spine 1] --- L1[Leaf 1]
  S1 --- L2[Leaf 2]
  S2[Spine 2] --- L1
  S2 --- L2
  L1 --- H1[Host]
  L2 --- H2[Host]
```

关键词：ECMP、Underlay、VXLAN、EVPN、东西向流量。

## 公有云 VPC

```mermaid
flowchart TB
  Internet --> IGW[Internet Gateway]
  IGW --> LB[Public LB]
  LB --> App[Private App Subnet]
  App --> DB[Private DB Subnet]
  App --> NAT[NAT Gateway] --> IGW
  VPN[VPN/专线] --> App
```

关键词：子网、路由表、NAT Gateway、安全组、负载均衡、专线/VPN。

## 混合云 Hub-Spoke

```mermaid
flowchart TB
  DC[本地数据中心] --> Hub[云 Hub<br/>防火墙/DNS/专线]
  Hub --> Spoke1[业务 VPC 1]
  Hub --> Spoke2[业务 VPC 2]
  Hub --> Internet[集中公网出口]
```

关键词：Transit、BGP、地址规划、回程路由、共享服务。

## 互联网 AS

```mermaid
flowchart LR
  UserISP[接入 ISP AS] --> Transit[Transit AS]
  Transit --> IXP[IXP]
  IXP --> CDN[CDN/云 AS]
  Transit --> RemoteISP[对端 ISP AS]
```

关键词：ASN、BGP、Peering、Transit、IXP、Anycast。
