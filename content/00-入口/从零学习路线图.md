# 从零学习路线图

适合完全新手。目标不是背术语，而是能看懂拓扑图、能解释一条流量为什么这样走、能知道排障时该看哪一层。

## 第一阶段：知道“包”如何在本地走

先读：

- [[OSI 与 TCP-IP 分层模型]]
- [[封装、解封装与 MTU]]
- [[二层网络与三层网络]]
- [[IP 地址、子网与 CIDR]]
- [[默认网关与下一跳]]
- [[ARP 与 IPv6 NDP]]

你需要能回答：

- 同一个网段的两台机器为什么不需要路由器？
- 不同网段为什么要找默认网关？
- MAC 地址和 IP 地址分别在什么时候用？
- 为什么 MTU 不匹配会导致“能 ping 小包，业务不通”？

## 第二阶段：知道局域网如何组织

先读：

- [[局域网基础拓扑]]

- [[VLAN 与 Trunk]]
- [[STP 与二层环路]]
- [[园区网三层架构]]
- [[防火墙、ACL 与安全域]]

你需要能回答：

- VLAN 是隔离广播域，不是天然安全边界。
- 三层交换机为什么既像交换机又像路由器？
- 防火墙为什么经常放在不同安全域之间？
- 二层环路为什么会把一个网络打爆？

先读：

## 第五阶段：把协议串起来

先读：

- [[DNS 协议]]
- [[DHCP 协议]]
- [[TCP、UDP 与 QUIC]]
- [[TLS、HTTP 与 HTTPS]]
- [[NAT、PAT 与 CGNAT]]
- [[负载均衡 L4-L7]]
- [[端到端实例：局域网到公网再到对端局域网]]

你需要能复述：

1. 主机拿到 IP 地址。
2. 主机解析域名。
3. 主机决定下一跳。
4. 主机用 ARP/NDP 找网关 MAC。
5. 网关、防火墙、NAT、运营商、互联网、对端边界逐跳转发。
6. TCP/TLS/HTTP 或 QUIC/HTTP/3 在端到端路径上完成应用通信。
