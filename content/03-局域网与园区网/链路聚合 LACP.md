# 链路聚合 LACP

## 链路聚合是什么

链路聚合把多条物理链路合成一条逻辑链路，提高带宽和冗余能力。LACP 是常见协商协议。

```mermaid
flowchart LR
  SW1[交换机 A] == Port-Channel/LAG == SW2[交换机 B]
```

实际可能是多根线：

```text
Eth1 + Eth2 + Eth3 + Eth4 -> Port-Channel 1
```

## 优点

- 单条链路故障时逻辑链路仍可用。
- 多条链路共享流量。
- 避免 STP 阻塞其中一条并行链路。

## 分流方式

LACP 通常按哈希分流，不是把一个连接拆成多条线。哈希字段可能包括：

- 源/目的 MAC。
- 源/目的 IP。
- 源/目的端口。

因此单条大流可能只能跑满一条成员链路。

## 常见场景

- 交换机上联。
- 服务器双网卡绑定。
- 防火墙/负载均衡上联。
- 存储网络。

## 常见问题

- 两端 LACP 模式不一致。
- 成员口速率/双工/VLAN 不一致。
- 一端聚合，一端没聚合，形成环路或丢包。
- 哈希不均导致某条链路拥塞。
