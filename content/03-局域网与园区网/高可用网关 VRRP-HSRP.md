# 高可用网关 VRRP-HSRP

## 为什么需要高可用网关

终端通常只配置一个默认网关。如果这个网关设备故障，即使交换网络还在，终端也无法跨网段通信。

高可用网关协议让多台三层设备共享一个虚拟网关 IP。

## 基本拓扑

```mermaid
flowchart TB
  PC[终端<br/>Gateway 192.168.10.1] --> SW[接入交换机]
  SW --> R1[网关 A<br/>真实 IP .2]
  SW --> R2[网关 B<br/>真实 IP .3]
  R1 -. 虚拟网关 192.168.10.1 .- R2
```

## 常见协议

- VRRP：标准协议。
- HSRP：Cisco 常见。
- GLBP：Cisco 负载分担网关协议。

## 工作方式

- 多台网关协商主备。
- 对终端暴露虚拟 IP 和虚拟 MAC。
- 主设备转发流量。
- 主设备故障后，备设备接管虚拟 IP/MAC。

## 注意事项

- 上下行链路故障都要跟踪，否则可能网关还活着但上游断了。
- 与 STP 根桥、VLAN 网关位置要协调。
- 有状态防火墙场景还要考虑会话同步。
- 云网络通常由平台提供虚拟网关，不需要你手工配置 VRRP。
