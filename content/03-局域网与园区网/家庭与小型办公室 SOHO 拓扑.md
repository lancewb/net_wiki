# 家庭与小型办公室 SOHO 拓扑

## 典型拓扑

```mermaid
flowchart LR
  Devices[手机/电脑/电视/摄像头] --> WiFi[家用路由器 Wi-Fi/交换]
  WiFi --> CPE[光猫/运营商 CPE]
  CPE --> ISP[运营商]
  ISP --> Internet[互联网]
```

很多家用“路由器”实际上集成了：

- 无线 AP
- 二层交换机
- 路由器
- DHCP 服务器
- DNS 转发器
- NAT 网关
- 简单防火墙

## 常见地址

家庭内网常用：

- `192.168.0.0/24`
- `192.168.1.0/24`
- `10.0.0.0/24`

家用路由器通常给终端发：

- IP 地址
- 子网掩码
- 默认网关
- DNS 服务器

## NAT

家里多台设备共用一个公网 IPv4 或运营商 CGNAT 地址访问互联网。家用路由器用 PAT 把不同内网连接映射到不同公网端口。

## 双 NAT

常见链路：

```text
手机/电脑 -> 家用路由器 NAT -> 光猫 NAT -> 运营商 CGNAT -> 互联网
```

双 NAT/多重 NAT 可能影响：

- 端口转发
- 游戏联机
- P2P
- 家庭 NAS 远程访问
- VPN 入站

## IPv6

如果运营商提供 IPv6，家庭设备可能拿到全球可路由 IPv6 地址。此时不一定需要 NAT，但仍然需要防火墙阻止不必要入站访问。

## 常见排障

- 只能连 Wi-Fi 但不能上网：看路由器 WAN 口。
- 能上网但打不开某些网站：看 DNS、IPv6、MTU。
- 远程访问家里服务失败：看公网 IP、CGNAT、端口转发、防火墙。
- 网络时快时慢：看 Wi-Fi 信道、弱信号、运营商链路、DNS。
